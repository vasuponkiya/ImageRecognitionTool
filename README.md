# 🧠 Image Recognition Tool

A Django-based web application that allows users to upload images and receive predictions from a trained machine learning model. Ideal for quick image classification tasks via a simple browser interface.

---

## 🚀 Features

- Upload image files for real-time prediction
- Uses a pre-trained deep learning model
- Django admin panel for managing the app
- Clean, simple frontend for easy use

---

## 🛠️ Tech Stack

- Python 3.x
- Django
- TensorFlow / Keras (or your ML model's library)
- SQLite (default database)
- HTML / CSS
